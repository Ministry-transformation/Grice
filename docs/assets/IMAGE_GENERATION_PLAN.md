# Image generation plan

Дата: 2026-10-03. Це артдирекція для **концептуальних ілюстрацій**. Реальні фото проєктів користувач додасть пізніше. Виконані на цьому етапі концепти задокументовані в `ASSET_INVENTORY.md`. Для `/stones` додано три крупні фактури чорного, сірого й червоного граніту; для `/monuments` — чотири окремі схеми форми: одинарна вертикальна, одинарна горизонтальна, подвійна вертикальна та подвійна горизонтальна; для `/artwork` — п’ять прикладів мотивів на чорному граніті: квітка, природа, символ, музичне захоплення та український орнамент.

## Напрям

Photorealistic premium editorial/documentary style; український/центральноєвропейський контекст без упізнаваних реальних місць; денне природне світло; коректні пропорції; теплий ivory, графіт, чорний/тепло-сірий камінь, природна зелень. Без логотипів, читабельних випадкових написів, водяних знаків, театрального туману, надмірного горя чи вигаданих конструктивних норм. Написи в UI накладати HTML/SVG.

## Правила використання

- Реальні project/case photos лишаються у черзі до матеріалів користувача.
- Не повторювати один image у сусідніх картках, якщо це створює враження різних виконаних робіт.
- На матеріальних swatches показати caveat: фактичний відтінок/наявність звіряються за фізичним зразком.
- Нижче fold — lazy loading; hero — відповідні розміри, `width/height`, compressed WebP/AVIF після генерації.
- Після генерації перевірити кожен output в браузері й занести фактичний файл, розмір та призначення до `ASSET_INVENTORY.md`.
