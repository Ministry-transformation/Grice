Дата: 2026-10-03
Джерела: поточний checkout, локальний preview `http://127.0.0.1:4324/Grice/`, надане `CODEX_MEMORIAL_SITE_MASTER_EXECUTION.md`. Файл `granite_memorial_site_research_2026.md` та інші `AGENTS.md` у checkout не знайдені.

## Коротко

В основи вже є цілісна editorial арт-дирекція: теплий ivory, графіт, серіфні заголовки, стримана бронза, великі фото, mobile-first стилі. Головна має шість напрямків і переконливий приклад; сторінка пам’яті містить біографію, хронологію, фото, фільтр медіа, галерею, діалоги та локальний preview спогаду. Шість сторінок послуг мають вступ, переваги, кроки, FAQ та форму.

Головна проблема — сайт поки що радше описує напрями, ніж допомагає вибрати й підготувати конкретний запит. Немає маршруту каталогу та сторінок моделей, палітри матеріалів, бібліотеки художніх рішень, повних сторінок портрета/напису, встановлення, благоустрою, цифрового продукту, контактів і прикладів робіт. Більшість фото — попередні ілюстрації, не фотографії виконаних замовлень.

## Інвентар проєкту

| Частина | Поточний стан |
|---|---|
| Framework/router | Astro 7, filesystem routes, TypeScript; статичний output |
| Deployment | GitHub Pages через `.github/workflows/pages.yml`; base `/Grice`; preview відкрито локально |
| CSS | Один `src/styles/gravis.css`, design tokens у `:root`, далі багато локальних значень і page-класів; брейкпойнти переважно 850/620 px |
| Components | Astro layout, data-driven service route та `LeadForm`; більшість header/footer/секцій повторені в сторінках |
| UI library | Немає зовнішньої component library; CSS та нативні HTML-елементи |
| Motion | Нативний JS/CSS, scroll behavior, transition; бібліотеки анімацій відсутні |
| Type | Cormorant Garamond, Manrope і Source Serif 4 підключені з Google Fonts; системний fallback не гарантований без мережі |
| Icons | Inline SVG на головній і текстові символи/Unicode в інших місцях |
| Images | `public/images/*.webp`; ручні URL, без CMS, генератора `srcset` або image pipeline |
| Content/data | `src/data/services.ts`; інші сторінки містять контент прямо в Astro |
| Forms | Browser validation → `mailto:info@gravis.ua`; нічого не зберігається на сервері; файлового upload немає |
| Analytics | У вихідному коді не знайдено |
| SEO | Title/description, sitemap і robots є; canonical, OG, structured data — не виявлені |

## Компоненти й взаємодії

| Pattern | Наявне використання | Оцінка |
|---|---|---|
| Header/mobile nav | Дублюється у home, service, memorial, 404; окремі короткі inline scripts | Працює, але навігацію треба уніфікувати для нових маршрутів |
| Footer/contact | Переважно дубльований у сторінках | Потребує спільного компонента та джерела бізнес-контактів |
| Buttons/cards/section wrappers | CSS-класи та розмітка по сторінках | Зберегти візуальний стиль, винести повторювані блоки для нових сторінок |
| Gallery/lightbox/tabs | Є лише на сторінці пам’яті | Уже функціонально опрацьовано; повторно не переписувати без доказу дефекту |
| FAQ | Нативний `details/summary` на service pages | Працює клавіатурою; перевикористати через shared component |
| Lead form | Є на service pages | Не має backend, міста/кладовища, upload, окремих help/error states для файлу |
| Before/after, selectors, comparison | Немає | Нові компоненти для зрозумілого вибору; без фальшивої точності |

## Візуальний і змістовий аудит

- **Сильні сторони:** виразний hero, впізнавані serif/ivory/bronze tokens, зрозумілі широкі секції, попередні мобільні виправлення, сторінка пам’яті має достатню композиційну глибину.
- **Головна:** блок з шістьма напрямками зберегти. Твердження «граніт преміум-якості» та «гарантія» не підкріплені доступними бізнес-даними. Візуального chooser, палітри каменю, реальних кейсів і upload CTA немає.
- **Service pages:** контент структурований, але сторінки схожі між собою й не дають моделей, матеріалів, варіантів комплектації чи змістовного вибору.
- **QR demo:** складна частина вже присутня та перевірялась раніше; фото/історія/аудіо не підтверджені як реальні матеріали. Зберегти demo з позначенням для використання в родині після погодження даних.
- **Зображення:** 21 WebP-файлів у `public/images`; картки послуг — 512×512; process-фото — приблизно 666–805×724; portrait — 1669×942. Головний hero показаний в локальному візуальному перегляді, але браузерний inventory повідомив `naturalWidth=0` для нього, тому asset і його шлях треба окремо переперевірити. Немає окремих продуктових фактур/деталей, galleries кейсів або гарантованих реальних фото.
- **Mobile:** попередній прогін підтвердив відсутність overflow на 320–1440 px та роботу основної навігації/форм. Нові сторінки потребують повторного проходу на 390/768/1024/1440 px.

## Технічні та SEO знахідки

1. `LeadForm` готує користувацьку email-чернетку, але серверної доставки/збереження немає; email не підтверджений.
2. Телефон `+380 67 123 45 67`, адреса `м. Київ, вул. Гранітна, 12`, години роботи й слова про гарантію не підтверджені окремим джерелом. Вони залишаються в поточному UI як business-data risks.
3. Немає upload flow; немає реальних фото кейсів.
4. Canonical/OG/schema відсутні; sitemap містить лише поточні маршрути.
5. CSS підключає Google Fonts; автономний fallback є, але перевірити slow/offline state треба після нових сторінок.
6. Ціни, availability/lead time, склад комплектації, точні розміри/товщини, географія та гарантійні умови не мають джерела.

## Висновок і принцип продовження

Зберегти основний візуальний характер home та memorial demo. Додати реальну IA, моделі-концепції й інструменти добору параметрів, але прямо позначити їх як побажання/візуальні концепти. До підтвердження бізнес-даних не показувати fake price, SKU, технічні характеристики, гарантію, наявність, реальні кейси чи реквізити.
