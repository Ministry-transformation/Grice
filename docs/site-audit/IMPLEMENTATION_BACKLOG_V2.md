# Backlog V2 — перед публічним запуском

Цей список містить роботу, що потребує бізнес-рішень або матеріалів власника. Поточні сторінки залишаються доступними локально.

## P0 — потрібне для реального прийому звернень

- Підтвердити email для `mailto:` або обрати й підключити сервіс/backend із потрібним зберіганням і захистом заявок.
- Перевірити UX листа на телефонах і desktop після того, як буде підтверджений реальний отримувач.
- Надати телефон, адресу/географію, години роботи або підтвердити, що їх не потрібно публікувати.
- За бажанням отримувати файли без ручного вкладення — обрати сховище, допустимі формати/ліміти, retention і повідомлення про обробку.

## P1 — комерційні дані й контент

- Підтвердити матеріали, походження/асортимент, фактичні техніки декорування, габарити, комплектації, ціни/метод розрахунку, строки, географію, гарантійні умови.
- Надати фото завершених робіт і дозвіл на публікацію; замінити концептуальні картки `works` реальними кейсами, лише з фактичними підписами.
- Погодити зміст реальних прикладів і замінити демо-фото/біографію сторінки пам’яті тільки за дозволом родини.
- Вирішити privacy/hosting lifecycle QR-сторінки: рівень доступу, індексація, згода на публікацію, модерація, резервні копії, експорт/видалення, строк підтримки URL/QR.
- Після отримання зразків каменю створити перевірену матеріальну палітру з точними назвами/позначками доступності.

## P2 — доробки після даних

- Розширити data-моделі каталогу й фільтри на підтверджені типи, кольори, форми та реальні виміри.
- Додати узгоджені приклади декоративних мотивів, підготовки портретів і благоустрою.
- Провести повторний контент-, accessibility- та SEO-прохід після заміни концептів на реальний портфель.
