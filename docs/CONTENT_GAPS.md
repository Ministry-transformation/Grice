# Content gaps — Gravis

Ці значення не виводяться з коду надійно, тому сторінки будуються так, щоб їх можна було підключити пізніше без вигаданих тверджень.

| Категорія | Відсутні/непідтверджені дані | Поведінка сайту до підтвердження |
|---|---|---|
| Ціни | прайс, мінімальна ціна, ціни «від», умови прорахунку | Не показувати суми чи діапазони; CTA на індивідуальний розрахунок |
| Матеріали | фактичний асортимент/походження/наявність граніту й декоративних матеріалів | Палітра ілюстративна; назви зі специфікації не трактувати як підтверджений запас |
| Розміри | стела, основа, квітник, custom limits | Не оголошувати стандартні розміри; запропонувати вказати побажання |
| Товщина/вага | доступні товщини та weight limits | Не задавати select із нібито доступними значеннями |
| Фініш/технології | полірування, різьба, лазер, піскоструй, V-cut, золочення, фотокераміка, скло, бронза | Описувати як питання для узгодження або залишити поза переліком гарантованих робіт |
| Комплектація | що входить у модель/пакет і які add-ons реально доступні | Concept card не має SKU/«входить у комплект»; склад підтверджується перед розрахунком |
| Монтаж | робоча зона, доставка, строки, підготовка основи, демонтаж, техніка, кладовищні вимоги | Не давати універсальних норм, строків або географії |
| Благоустрій | матеріали, колір, аксесуари, рівень догляду | Chooser — побажання до пропозиції, availability уточнюється |
| Гарантія | строк, покриття, виключення | Видалити непідтверджене слово «гарантія» з публічного proof |
| Докази | реальні роботи, відгуки, сертифікати, команда, історія компанії | Не публікувати фейкові case studies/reviews; показувати concept art з помітною міткою |
| Контакти | телефон `+380 67 123 45 67`, адреса `м. Київ, вул. Гранітна, 12`, години, `info@gravis.ua` не підтверджені користувачем | Не додавати нові контактні факти; винести в одну змінну/налаштування й позначити як verify-before-launch |
| Lead destination | backend/form service/доступна email-адреса | Front-end валідація і user-controlled draft; не казати, що сайт зберіг/отримав заявку |
| Вкладення | допустимі формати, максимальний розмір, destination storage | Локально перевіряти формат/розмір і давати інструкцію прикріпити вручну; не завантажувати на сервер |
| Digital memory | власник даних, public/unlisted/PIN, noindex, moderation, строк зберігання, subscription, backup/export, перенесення admin, deletion, permanent redirect/QR longevity | Показувати тільки готове demo; privacy/longevity рішення позначити як предмет погодження |
| Demo memory | справжність біографії/сімейних історій, дозволи на фото/голос/відео | Не називати real memorial; зберегти явний demo/local preview disclosure |

### Потрібно від власника для наступного кроку

Перед public release потрібні реальні контактні дані і email destination; підтверджені матеріали/техніки/географія/ціни або спосіб розрахунку; дозволені фотографії реальних замовлень; рішення щодо серверного прийому заявок і privacy/hosting моделі для QR-пам’яті.
