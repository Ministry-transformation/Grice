# Grice

Grice company website and memorial example page, built with Astro.

## Local development

```sh
npm ci
npm run dev
```

- Company website: `http://localhost:4321/`
- Memorial example: `http://localhost:4321/memory/oleksandr-kovalenko`

## Deployment

Pushing to `main` builds the static site and deploys it to GitHub Pages at `https://ministry-transformation.github.io/Grice/`.

The photos on the memorial example are generated illustrations, not documentary photos. Replace them with family-approved images before using the page as a real memorial. Audio and video cards are visual examples until recordings are supplied. The memory form only displays a local preview and does not send or save submitted text. Verify all business contact details before launch.
